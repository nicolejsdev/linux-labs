# 🐧 Linux Labs

Laboratórios práticos de Linux feitos durante minha transição para **DevOps e Cloud**. Cada lab tem um objetivo, o passo a passo com os comandos executados, evidências (screenshots) e os aprendizados.

## 📚 Laboratórios

| # | Lab | O que pratiquei |
|---|-----|-----------------|
| 01 | [Linux Fundamentals](01-linux-fundamentals) | Fundamentos de Linux e linha de comando |
| 02 | [Users & Permissions](02-users-permissions) | Usuários, grupos, `chmod`, `chown` e troubleshooting de `Permission denied` |
| 03 | [Processes & Background](03-processes-background) | PID, jobs, `ps`, `kill` e `top` |
| 04 | [Services](04-services) | `systemd`, `systemctl`, start x enable e `ssh.socket` |
| 05 | [Storage & Filesystems](05-storage-filesystems) | `df`, `lsblk`, `findmnt`, `du` e limpeza controlada de disco |
| 06 | [Networking](06-networking) | Interfaces, IP, gateway e rotas com `ip addr` e `ip route` |
| 07 | [Bash Scripting](07-bash-scripting) | Primeiro script Bash com `$(...)` e `chmod +x` |

## 🧰 Ambiente

- Ubuntu Linux (<!-- ex: 24.04 LTS -->)
- Terminal `bash`
- Editor: VS Code

## 🗂️ Estrutura

Cada pasta segue o mesmo padrão:

```text
NN-nome-do-lab/
├── README.md        # objetivo, passo a passo, troubleshooting e aprendizados
└── screenshots/     # evidências da execução
```

## 🔍 Abordagem

Em todos os labs, sigo o mesmo raciocínio de troubleshooting: **identificar, coletar informações, agir e confirmar o resultado**.
